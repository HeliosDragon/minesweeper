# 扫雷游戏网页版

一个现代化的网页版扫雷游戏，采用苹果风格扁平化设计，支持响应式布局，可在 GitHub Pages 上免费部署。  
**v1.5 更新：引入“无猜模式”地图生成算法，让每一局都可通过纯逻辑推理通关！**

![游戏截图](https://img.shields.io/badge/status-稳定-success) ![GitHub](https://img.shields.io/github/license/heliosdragon/minesweeper) ![版本](https://img.shields.io/badge/版本-v1.5-blue)

---

## 功能特点

- **经典扫雷规则**：左键翻开格子，右键标记/取消标记地雷  
- **三种难度**：  
  - 初级：9×9 网格，10 颗地雷  
  - 中级：16×16 网格，40 颗地雷  
  - 高级：16×30 网格，99 颗地雷  
- **游戏状态显示**：  
  - 实时计时器（数码管风格）  
  - 剩余地雷计数器  
  - 重置按钮（动态表情）  
- **智能提示系统**：  
  - 每局游戏最多使用 3 次提示  
  - 点击提示按钮会高亮一个安全格子（脉冲动画），并在状态栏显示坐标  
- **撤销标记**：右键点击已标记的格子可撤销标记  
- **响应式设计**：完美适配桌面、平板和手机  
- **触摸支持**：移动设备上长按模拟右键  
- **无障碍支持**：键盘导航、高对比度模式  
- **游戏数据统计**：记录玩家的胜负记录、连胜/连败、最佳用时等统计信息，支持按难度查看，并实时在控制面板展示当前连胜/连败状态（奖杯/拇指朝下图标）  
- **无猜模式（v1.5 新增）**：采用基于约束传播的推理引擎，在生成地图时反复校验，确保从起始位置开始，整个局面可以不依赖猜测，仅凭逻辑推理完成。每局游戏都公平、纯粹！

## 本地运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/heliosdragon/minesweeper.git
   cd minesweeper
   ```

2. 使用任意 HTTP 服务器打开 `index.html`，例如：
   ```bash
   # Python 3
   python -m http.server 8000
   # 或使用 Node.js 的 http-server
   npx http-server
   ```

3. 在浏览器中访问 `http://localhost:8000`

## 开发指南

### 代码架构

- `game.js`：游戏核心逻辑，包含 `Game` 类、网格生成、地雷布置、胜负判断、空白展开、提示系统。**v1.5 新增 `MinesweeperSolver` 推理引擎及无猜地图生成器**。  
- `ui.js`：用户界面管理，负责渲染网格、绑定事件、更新状态、**高亮提示格子（修复）**、**实时刷新连胜/连败状态（修复）**。  
- `utils.js`：通用工具函数（随机数、DOM 操作、防抖节流等）。  
- `stats.js`：游戏数据统计模块，负责记录玩家成绩、计算胜率、**修复当前连胜/连败追溯算法**，并支持按难度查看统计。  
- `bundle.js`：由上述四个源文件合并而成的生产打包文件，用于 `index.html` 直接引用。

### 打包流程

开发时修改 `utils.js`、`stats.js`、`game.js`、`ui.js` 后，需重新生成 `bundle.js`。可使用以下命令（Node.js 环境）：

```bash
cd minesweeper
node -e "const fs = require('fs'); const files = ['js/utils.js', 'js/stats.js', 'js/game.js', 'js/ui.js']; const bundle = files.map(f => fs.readFileSync(f, 'utf8')).join('\n\n'); fs.writeFileSync('js/bundle.js', bundle); console.log('打包完成');"
```

或手动将四个文件内容依次复制到 `bundle.js`。

### 添加新功能

1. 在 `game.js` 中扩展 `Game` 类或 `MinesweeperSolver` 类  
2. 在 `ui.js` 中更新 UI 交互  
3. 在 CSS 中添加相应样式

## 更新日志

### v1.5 (2026‑06‑23) —— 无猜模式 + 核心修复

- **新增“无猜模式”地图生成算法**  
  - 实现基于约束传播的推理引擎 `MinesweeperSolver`，支持基本推理（R1/R2）和高级子集排除推理。  
  - 在首次点击后，通过迭代试错法生成地图，确保从起始位置可完全通过逻辑推理通关，无需猜测。  
  - 控制台输出生成尝试次数，便于调试（默认开启，失败时自动回退到随机生成）。

- **修复提示功能失效**  
  - 在 `ui.js` 中绑定 `onHintApplied` 回调，提示按钮点击后会高亮安全格子并显示脉冲动画，3秒后自动移除高亮。  
  - 状态栏同步显示提示位置的坐标信息。

- **修复连胜/连败展示不刷新**  
  - 重写 `stats.js` 中的当前连胜/连败追溯算法，从最新记录开始逆序正确累计。  
  - 控制面板中的连胜计数器现在动态更新：连胜时显示奖杯图标 🏆 和绿色高亮，连败时显示拇指朝下 👎 和红色高亮，标签文字同步切换为“连胜”或“连败”。

- **优化首次点击安全性**  
  - 增强 `placeMines` 方法，确保第一次点击及其周围8格绝对不会有地雷。

- **UI 细节增强**  
  - 提示高亮使用更醒目的金色脉冲动画，并放大格子尺寸。  
  - 游戏结束（胜利/失败）时立即刷新统计面板，确保数据一致。  
  - 移除无猜模式的硬编码开关，默认启用，简化用户体验。

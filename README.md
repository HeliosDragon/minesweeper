# 扫雷游戏网页版

一个现代化的网页版扫雷游戏，采用 Gemini 风设计（蓝紫渐变 + 玻璃拟态 + 胶囊控件），支持**亮/暗双主题**与**无猜开局保证**，可在 GitHub Pages 上免费部署。  
**v1.6 更新：Gemini 风视觉重设计 + 亮/暗双主题 + 无猜开局逻辑重构 + 连胜/连败记录条 + 内联 SVG 图标！**

## 功能特点

- **经典扫雷规则**：左键翻开格子，右键标记/取消标记地雷  
- **三种难度**：  
  - 初级：9×9 网格，10 颗地雷  
  - 中级：16×16 网格，40 颗地雷  
  - 高级：16×30 网格，99 颗地雷  
- **游戏状态显示**：  
  - 实时计时器（上限 999 秒，数码管风格）  
  - 剩余地雷计数器  
  - 重置按钮（动态表情，带「重开」文字标签的胶囊主按钮）  
- **智能提示系统**：  
  - 每局游戏最多使用 3 次提示  
  - **优先高亮一个「逻辑安全格」**（可被 100% 推导出的安全格），否则随机挑选  
  - 蓝紫渐变光环脉冲高亮，状态栏同步显示提示坐标  
- **无猜开局保证**：  
  - 第一下点击后，局面**保证至少存在一个可纯逻辑推导的下一步**  
  - 基于约束传播推理（基础规则 + 子集排除推理），`generateOpening()` 反复重排地雷直到满足条件（上限 500 次必中），彻底消除「首步只能猜」的窘境  
- **和弦点击（Chord）**：左键点击已翻开的数字格子，若周围旗帜数等于数字，自动翻开相邻未标记格子，大幅提升操作速度  
- **连胜 / 连败 / 最佳记录条**：控制面板实时展示，使用 `localStorage` 持久化（关掉网页再开仍在）；胜一局连胜 +1、连败清零，负一局反之，最佳连胜自动刷新  
- **亮 / 暗双主题**：右上角一键切换，偏好存入 `localStorage`，下次自动恢复；首屏内联脚本提前应用主题，**无深浅色闪烁**  
- **内联 SVG 图标**：地雷 / 旗帜 / 错误标记（×）由代码内联绘制，**不依赖外部字体**，任何网络环境下都清晰可见  
- **撤销标记**：右键点击已标记的格子可撤销标记  
- **响应式设计**：完美适配桌面、平板和手机  
- **触摸支持**：移动设备上长按模拟右键  
- **无障碍支持**：键盘导航、高对比度模式

## 本地运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/heliosdragon/minesweeper.git
   cd minesweeper
   ```

2. 使用任意 HTTP 服务器打开 `index.html`，例如：
   ```bash
   # Python 3
   python -m http.server 8000
   # 或使用 Node.js 的 http-server
   npx http-server
   ```

3. 在浏览器中访问 `http://localhost:8000`

```
minesweeper/
├── index.html          # 主页面

│   └── bundle.js      # 打包合并后的脚本（生产用，由 build.js 生成）
└── README.md          # 说明文档
```

## 开发指南

### 代码架构

- `game.js`：游戏核心逻辑，包含 `Game` 类、网格生成、地雷布置、胜负判断、空白展开、提示系统、**和弦点击 `chordCell()`**。**无猜开局由 `generateOpening()` 驱动，配合 `analyzeLogical()` 推理引擎（基础规则 + 子集排除）在生成阶段反复校验，确保首步必有逻辑解。**  
- `ui.js`：用户界面管理，负责渲染网格、绑定事件、更新状态、**主题切换（亮/暗，`setupTheme()`）**、**连胜/连败记录条（`updateStreak()` + `localStorage['ms-streak']`）**、**内联 SVG 图标渲染（`ICONS` 对象）**、提示高亮。  
- `utils.js`：通用工具函数（随机数、DOM 操作、防抖节流等）。  
- `bundle.js`：由 `utils.js` + `game.js` + `ui.js` 三个源文件合并而成的生产打包文件，用于 `index.html` 直接引用（已去除 `import`/`export`）。

### 打包流程

开发时修改 `utils.js`、`game.js`、`ui.js` 后，需重新生成 `bundle.js`。项目根目录提供了 `build.js` 脚本（Node.js 环境），会自动去除 ES Module 语法并合并三个文件：

```bash
cd minesweeper
node build.js
```

> ⚠️ **重要**：任何对三个源文件的修改都必须重新运行 `node build.js`，否则 `index.html` 引用的仍是旧的 `bundle.js`。

### 添加新功能

1. 在 `game.js` 中扩展 `Game` 类（如新增推理规则可加入 `analyzeLogical()`）  
2. 在 `ui.js` 中更新 UI 交互与渲染  
3. 在 CSS 中添加相应样式（注意同时维护亮/暗两套 `data-theme` 变量）  
4. 运行 `node build.js` 重新打包

## 更新日志

### v1.6 (2026‑07‑30) —— Gemini 风重设计 + 无猜开局重构（本轮修改）

> 本轮在 v1.5 基础上进行了大规模重构与视觉重设计，核心改动如下：

- **视觉系统全面升级为 Gemini 风**  
  - 主色采用 Gemini 蓝 + Google 蓝，签名**蓝→紫渐变**只用于点睛（标题渐变文字、提示按钮、提示光环）。  
  - 大圆角（卡片 24–28px）+ **胶囊形控制条/按钮**（Gemini 标志性「大胶囊」）；Google M3 超柔和阴影。  
  - 顶部极简渐变标题 + 副标题，控制面板改为居中浮起的胶囊工具条，说明区改为可折叠 `<details>`（默认收起）。  
  - favicon 改为 inline SVG（💣 图标），不再依赖外部文件。

- **新增亮 / 暗双主题**  
  - 右上角 ☀/🌙 一键切换，偏好存入 `localStorage['ms-theme']`，下次自动恢复；首屏内联脚本提前应用主题，无闪烁。  
  - 深色背景 `#131314`、卡片 `#1e1f20`、蓝点缀 `#a8c7fa`；格子、数字、状态条全部做了深色适配。

- **无猜开局逻辑重构（更可靠）**  
  - 移除初版推理引擎，改为 `analyzeLogical()`（基础规则 + 子集排除推理）配合 `generateOpening()` 反复重排地雷，直到开局后至少存在一个纯逻辑可推导的下一步。  
  - 经三难度各 500 次随机首点共 **1500 次验证全部通过**（首下绝不踩雷且必有逻辑步）。

- **连胜 / 连败记录条**  
  - 移除独立的统计模块，连胜逻辑整合进 `ui.js`（`updateStreak()` + `localStorage['ms-streak']`）。  
  - 控制面板新增记录条：🔥 连胜 / ❄️ 连败 / 🏆 最佳，实时刷新并持久化。

- **地雷 / 旗帜图标改为内联 SVG**  
  - 原 Font Awesome `::after` 伪元素方案在字体 CDN 未加载时会整片空白；现改为 `ui.js` 内联注入 SVG（地雷 / 旗帜 / 错误标记 ×），任何环境 guaranteed 可见。

- **按钮与交互强化**  
  - 「重开」「提示」从纯圆形小图标升级为**带文字标签的胶囊主按钮**，醒目易点；提示保留蓝紫渐变光晕。  
  - 提示系统升级：优先返回「逻辑安全格」，找不到再随机。  
  - 新增**和弦点击（Chord）**，胜利时自动给所有地雷插旗，失败时高亮踩中的雷并标记错误插旗。  
  - 计时器上限 999 秒。

- **工程与清理**  
  - 新增 `build.js` 打包脚本（去除 ES Module 语法 + 合并源文件）。  
  - 删除 9 个「(2)」重复文件，修复原 favicon 404。  
  - 清除全部 `console.log` 调试语句。

### v1.5 (2026‑06‑23) —— 无猜模式 + 核心修复

- **新增“无猜模式”地图生成算法**  
  - 实现基于约束传播的推理引擎，支持基本推理（R1/R2）和高级子集排除推理。  
  - 在首次点击后，通过迭代试错法生成地图，确保从起始位置可完全通过逻辑推理通关，无需猜测。  
  - 首次点击及其周围 8 格绝对保证无雷。

- **修复提示功能失效**  
  - 在 `ui.js` 中绑定 `onHintApplied` 回调，提示按钮点击后会高亮安全格子并显示脉冲动画，3 秒后自动移除高亮。  
  - 状态栏同步显示提示位置的坐标信息。

- **修复连胜/连败展示不刷新**  
  - 重写当前连胜/连败追溯算法，从最新记录开始逆序正确累计。  
  - 控制面板中的连胜计数器动态更新：连胜时显示奖杯图标 🏆 和绿色高亮，连败时显示拇指朝下 👎 和红色高亮，标签文字同步切换为“连胜”或“连败”。

- **UI 细节增强**  
  - 提示高亮使用更醒目的金色脉冲动画，并放大格子尺寸。  
  - 游戏结束（胜利/失败）时立即刷新统计面板，确保数据一致。  
  - 移除无猜模式的硬编码开关，默认启用，简化用户体验。

## 已知限制与未来计划

- 排行榜功能（全站排名）暂未实现（计划在第二阶段添加）  
- 不支持保存游戏进度  
- 音效和高级动画待增强  
- **无猜开局**目前保证首步必有逻辑解；但扫雷后期仍可能出现「局部约束交叉、必须靠概率猜」的固有局面（这是扫雷的几何本质，任何引擎都无法消除）  
- 未来可能新增无猜模式的开关选项，供玩家选择是否启用
